# Как посмотреть новую Landing Page

## ⚠️ Важно!

Новая красивая страница находится по адресу:
```
http://localhost:3000/landing
```

**НЕ на главной странице** `http://localhost:3000/`

## Быстрый старт

```bash
# 1. Перейдите в папку frontend
cd src/frontend

# 2. Установите зависимости (если ещё не установлены)
npm install

# 3. Запустите сервер разработки
npm run dev

# 4. Откройте в браузере
# http://localhost:3000/landing
```

## Если страница не обновилась

Сделайте жёсткую перезагрузку (очистка кэша):
- **Windows/Linux:** `Ctrl + Shift + R`
- **Mac:** `Cmd + Shift + R`

## Проблемы?

Если страница всё равно не отображается правильно:

1. Очистите кэш и node_modules:
```bash
cd src/frontend
rm -rf node_modules .next
npm install
npm run dev
```

2. Убедитесь, что используете Node.js 18+:
```bash
node --version
```

3. Проверьте консоль браузера (F12) на ошибки
